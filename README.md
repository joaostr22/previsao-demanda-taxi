# Previsão de Demanda Horária de Táxi (Séries Temporais) 

## 🎯 Objetivo

Prever o número de pedidos de táxi para a próxima hora usando técnicas de séries temporais e regressão.

## 🧠 Como fiz o projeto

Reamostrei os dados para intervalos diferentes, estudei tendência e sazonalidade e criei lags temporais para modelagem. Comparei diferentes modelos de regressão e otimizei hiperparâmetros até atingir RMSE ≤ 48, conforme exigido.

## 🚀 Tecnologias
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
